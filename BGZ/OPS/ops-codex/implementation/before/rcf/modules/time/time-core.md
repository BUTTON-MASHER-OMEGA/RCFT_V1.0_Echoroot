### *Event Ordering with an Optional Linear-Unitary Refinement Representation*

The authoritative Time Core defines event identity and ordering. This document also retains a linear-unitary refinement construction as an optional downstream representation.

Time in RCF is **not a background dimension** and **not a global clock**.
It is a **refinement‑indexed ordering relation** that emerges only once discrete events exist.

This file records:
- how Time orders events through declared successor structure;
- how indexed differences may represent change;
- an optional linear-unitary representation that consumers may adopt explicitly.

It does **not** depend on relational structure, geometry, constraint density, or operator‑level content.

---

## 1. Axiom T — Emergent Time

Temporal order is not assigned before a first admitted event:

- The first event is labeled \( n = 1 \).
- There is no \( t_0 \) and no continuous time prior to D₁.
- Time is an **operational ordering**, not a dimension.

RCF does **not** posit a global “now.”
Each system or region carries its own refinement‑indexed temporal structure.

---

## 2. Event Index — Discrete Successor Ordering

The event index is:



\[
n \in \mathbb{N}, \quad n \ge 1
\]



It defines a **discrete successor ordering**:



\[
n \rightarrow n+1
\]



This ordering is:
- acyclic,
- discrete,
- system‑local,
- independent of relational or geometric structure.

It provides an index for refinement steps and other downstream records. Causal, memory, and dynamical interpretations remain downstream.

---

## 3. Optional Forward-Difference Representation

An adopting module may represent indexed change with the forward difference:



\[
\Delta_n X = X_{n+1} - X_n
\]



This is a representation choice, not a Time-owned update law. A continuous approximation requires an explicit limiting construction.

---

## 4. Optional Refinement Parameter \( \tau \)

An adopting continuous-refinement profile may introduce:



\[
\tau \in \mathbb{R}
\]



It is **not** physical time.
It indexes the profile's declared refinement family.

Refinement time is defined **per system or region** and does not impose global simultaneity.

---

## 5. Optional Linear-Unitary Refinement Operator

The following construction is not implied by the Event Axiom or the Time interface. It applies only when a downstream module explicitly supplies a Hilbert space and adopts this profile.

Refinement evolution is generated by a family of operators:



\[
U(\tau_2,\tau_1): \mathcal{H} \rightarrow \mathcal{H}
\]



satisfying:

### 5.1 Composition


\[
U(\tau_3,\tau_2)\,U(\tau_2,\tau_1) = U(\tau_3,\tau_1)
\]



### 5.2 Linearity


\[
U(\tau)(\alpha\psi + \beta\phi)
= \alpha\,U(\tau)\psi + \beta\,U(\tau)\phi
\]



Linearity supplies the profile's declared additive representation.

### 5.3 Unitarity


\[
U(\tau)^\dagger U(\tau) = I
\]



Unitarity preserves the adopted inner product. Probability, symplectic, Higgs, mass, and other physical readings are owned by downstream modules and are not Time claims.

### 5.4 Generator


\[
U(\tau_2,\tau_1) = \exp[-i(\tau_2 - \tau_1) H]
\]



with an optional compatibility condition:



\[
[H, d\rho(X)] = 0 \quad \forall X \in \mathfrak{stab}(h)
\]



when an adopting module declares \(d\rho\), \(\mathfrak{stab}(h)\), and the structure that condition preserves. Here \(H\) is a profile generator, not a Time-owned Hamiltonian.

## 6. Locality and Scale‑Relativity of Temporal Structure

RCF time is not a single global chain.
Each system carries its own temporal index over its admissible relational updates.
Subsystems carry their own local temporal indices, and a containing system carries an event index over relations between systems, including external relations not reducible to internal subsystem dynamics.

Temporal structure is therefore:
- **local**,
- **recursive**,
- **scale‑relative**,
- **and stitched together only through relations across scales**,
not globally uniform.

Time in RCF is a hierarchy of lawful event orderings, not a universal clock or background timeline.
