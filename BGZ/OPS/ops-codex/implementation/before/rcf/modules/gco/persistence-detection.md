### *Stable Patterns Across Time and Scale*

Persistence detection identifies **stable relational patterns** that emerge from recursive LCO dynamics across time and scale.

It answers:

> *Which relational motifs and structures persist under continued local coherence evaluation?*

---

## 1. Inputs

Persistence detection consumes:

- global coherence metrics,
- time‑indexed local coherence outcomes,
- subsystem–container relationships,
- cross‑scale relational links.

It does **not** consume:

- geometric information,
- explicit temporal control,
- operator‑level update rules (beyond LCO outcomes).

---

## 2. Persistent Patterns

Examples of persistence targets:

- **Relational motifs** that recur with low mismatch cost,
- **Subsystem configurations** that remain stable under refinement,
- **Cross‑scale alignments** that persist across many events,
- **Low‑cost pathways** that are repeatedly selected by LCO.

Persistence is:

- **relational**, not geometric,
- **global**, not local,
- **slow**, not eventwise.

---

## 3. Detection Criteria (Conceptual)

A pattern is considered persistent if:

- it recurs over many events,
- it maintains low local coherence cost,
- remains repeatedly selected or preserved under LCO update outcomes
- it remains compatible with container‑level structure,
- it survives cross‑scale aggregation.

These criteria are implemented using the metrics defined in `global_coherence_metrics.md`.

---

## 4. Outputs

Persistence detection produces:

- a set of identified persistent patterns,
- stability indicators (stable / metastable / transient),
- cross‑scale persistence summaries.

These outputs feed into:

- `structural_viability.md` (for global classification),
- downstream modules (e.g., geometry, policy) for interpretation.

---

## 5. Status

Persistence detection is the pattern‑recognition layer of GCO.
It identifies which relational structures endure under recursive local coherence dynamics.
