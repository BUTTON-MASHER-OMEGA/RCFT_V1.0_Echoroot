# Geometry-Adjacent Interface

## Document Contract

- owner: RCF geometry-adjacent profile
- type: Contract
- scope: optional survivor-pattern and symmetry descriptors
- authority: tier-8 optional geometry descriptor interface
- upstream dependencies: `/modules/geometry/discrete/interface.md` and `/modules/geometry/continuous/interface.md`
- status: active
- purpose: expose optional pattern labels derived from documented geometry records
- anti-backflow: adjacent descriptors may not override the geometry stack, create admissibility laws, or require their pattern vocabulary in other models

## Inputs

The profile may consume read-only survivor records, projected shadow records, plateau labels, mode records, and declared symmetry checks.

## Outputs

It may expose survivor properties, plateau behavior, mode structure, symmetry alignment, and representation-pattern labels with source provenance.

## Prohibitions

The profile may not select survivors, alter projection, define metrics or dynamics, infer physical meaning, or universalize candidate-specific patterns.
