# SMGv2.1 Gauge Translation Bridge

## Purpose

This file defines the SMGv2.1 translation bridge from Chromatic-12 semantic subsets to downstream gauge-language forms.

This is a translation file.
It is not a binding file and does not claim that gauge groups are upstream facts.

---

## 1. Translation Scope

SMGv2.1 maps:

- `Octet` to downstream `SU(3)`-style gauge language
- `Triplet` to downstream `SU(2)`-style gauge language
- `Singlet` to downstream `U(1)`-style gauge language

These are SMGv2.1-authorized downstream approximations.
They remain downstream semantic forms.
