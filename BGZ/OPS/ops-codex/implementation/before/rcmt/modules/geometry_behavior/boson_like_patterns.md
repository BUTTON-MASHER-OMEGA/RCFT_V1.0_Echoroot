- owner: RCMT Geometry-Behavior

- depends_on: `geometry_behavior_contract.md`, `echoon_field.md`, and `closure_reinjection_cycles.md`

## Purpose

This file defines optional RCMT labels for higher-order patterns assembled from valid echoon-pattern records, mismatch-gradient records, and closure-reinjection sequences.

The label **boson-like** denotes a downstream analogy. It is not an imported Standard Model label, a particle claim, or a physical field claim.

## Admission Rule

A `boson-like-pattern-record` is admissible only when:

- every constituent record conforms to the Geometry-Behavior contract;
- all constituent neighborhoods are connected by explicit adjacency;
- all echoon transitions are imported as allowed;
- the grouping criterion is declared;
- and the output remains provisional.

## Candidate Classes

### Adjustment Pattern

A local pattern correlated with an admissible change in a survivor offset or phase-cycle record.

### Signal-Like Pattern

An ordered adjacency path of compatible echoon-pattern records. The label does not imply information content or spacetime transmission.

### Resonance-Like Pattern

A repeated finite arrangement involving compatible echoon and survivor records. The label does not imply harmonic dynamics or an intrinsic frequency.

### Mediating Pattern

A local pattern associated with admissible changes in two or more adjacent survivor records. The label does not imply an exchanged particle or force carrier.

## Propagation Description

Pattern propagation requires an explicit chain of adjacent records and allowed transitions. No endpoint may be updated solely because another endpoint changed.

## Stability Labels

A pattern may be labeled:

- persistent, when its classification recurs under the same criterion;
- changed, when a later record has a different valid classification;
- terminated, when no qualifying later record exists;
- unresolved, when required support is missing.

These labels do not define intrinsic lifetime or decay law.

## Downstream Correspondence

A downstream physics interface may test correspondence between a pattern class and a physical semantic label. That test belongs downstream and must not be written back into this module as evidence.

## Prohibitions

This file does not permit:

- boson identity;
- gauge-field ontology;
- force mediation as an established mechanism;
- information transfer beyond adjacency;
- continuous wave equations;
- hidden phase variables;
- or promotion of analogy labels to canonical operators.

## Output

The output is an optional `boson-like-pattern-record` whose canonical content is its traceable constituent Geometry-Behavior records.
