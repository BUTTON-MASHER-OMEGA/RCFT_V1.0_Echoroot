## 1. Purpose

This file defines the current RCMT interpretation of the tau-like survivor regime.

Within the current interpretation, the tau-like regime represents the highest-compression charged-lepton persistence state currently considered within the charged-lepton survivor class.

This file remains downstream-scoped and does not replace Standard Model tau formalisms.

---

## 2. Core Interpretation

The current RCMT interpretation treats the tau-like regime as:

> a single-phase charged-lepton survivor occupying a high-compression persistence regime near the current 600-cell persistence boundary.

Within this interpretation:

* refinement burden is high,
* persistence windows are narrow,
* and survivor stability is significantly reduced relative to electron-like and muon-like regimes.

The tau-like regime remains a member of the charged-lepton survivor class.

---

## 3. Survivor Structure

The tau-like regime remains:

* single-phase,
* externally compact,
* non-cycling,
* and unconstrained by confinement-style closure requirements.

No internal A/B/C phase cycle is required.

The primary distinction is increased compression pressure and associated refinement burden.

---

## 4. Persistence Boundary Interpretation

Within the current RCMT direction, the tau-like regime occupies the final charged-lepton persistence state currently considered before 600-cell survivor organization ceases to be the preferred admissible configuration.

The current interpretation does not treat the tau as a distinct geometry.

Instead, it is interpreted as:

> the highest-compression survivor regime of the same underlying 600-cell → 120-cell persistence architecture.

As compression increases, refinement burden rises until the 600-cell survivor can no longer maintain stable persistence.

The detailed transition behavior beyond that boundary remains unresolved.

---

## 5. High-Compression Reference Geometry

Current survivor evaluations use:

```text
4_21 / E8
```

as a reference geometry for high-compression studies.

This choice is practical and model-local.

It reflects:

* current simulation work,
* triangle-packing compatibility,
* and existing survivor evaluations.

This file does **not** claim:

* that tau-like structures are E8 structures,
* that E8 represents a particle,
* or that 4_21 is the only possible high-compression organization.

The current interpretation only treats 4_21 as a useful reference geometry for studying compression regimes beyond the current 600-cell persistence boundary.

## 6. Projection Behavior

Despite elevated compression pressure, the tau-like regime remains externally compact.

Within this interpretation:

* internal survivor structure remains difficult to resolve externally,
* and projection continuity remains sufficiently stable to preserve point-like observational behavior.

Point-like behavior is treated as:

> low externally resolvable internal mismatch structure under projection,

not literal dimensionless ontology.

## 8. LCO Work Profile

The current interpretation treats the tau-like regime as the highest-work charged-lepton state currently considered.

Characteristics include:

* elevated refinement burden,
* increased mismatch management,
* narrow persistence windows,
* and strong sensitivity to compression pressure.

Mass-like behavior is interpreted as sustained refinement work required to preserve survivor persistence in this regime.

---

## 9. Decay Interpretation

Within the current interpretation:

* the tau-like regime occupies a near-boundary persistence state,
* and may be followed over a narrow recorded interval by lower-work admissible survivor classifications.

Decay is interpreted as:

> loss of admissibility for continued persistence near the current 600-cell persistence boundary.

The detailed renegotiation pathway remains outside the scope of this file.
