This directory explores a candidate RCMT interpretation of lepton-like survivor structures.

Within the current interpretation, leptons are modeled as:

* single-phase survivor configurations,
* shallow or compression-bounded offset regimes,
* and externally compact 120-cell-derived projections.

Unlike baryon-like structures, leptons do not require:

* multi-phase A/B/C persistence cycles,

## Core Interpretation

The current RCMT interpretation treats lepton-like structures as:

> stable or metastable single-phase survivor regimes whose projected behavior is determined by offset depth, compression pressure, and sustained LCO refinement work.

Within this interpretation:

* Electron-like regimes correspond to low-compression, low-work survivor persistence.
* Muon-like regimes correspond to higher-work single-phase persistence under increased compression pressure.
* Tau-like regimes correspond to near-terminal single-phase persistence approaching high-compression transition pressure.
* Neutrino-like regimes correspond to shallow or weakly coupled survivor offsets with minimal externally resolvable mismatch.

These interpretations remain provisional and model-local.

This directory records the current lepton profile and does not exclude future downstream lepton models built from the same upstream records.

## Single-Phase Persistence

The current interpretation treats leptons as single-phase survivor structures.

Within this interpretation:

* no internal A/B/C phase-cycle is required,
* no confinement-like closure is needed,
* and persistence is maintained through local admissibility under comparatively low mismatch burden.

This distinguishes lepton-like structures from baryon-like structures within the current RCMT direction.

## Compression-Regime Interpretation

The current interpretation treats generation-like behavior as a survivorship/compression-regime phenomenon.

Within this interpretation:

* Electron-like regimes occupy low-compression survivor states.
* Muon-like regimes occupy intermediate compression regimes approaching higher-friction geometric pressure.
* Tau-like regimes occupy high-compression regimes approaching the current `4_21` / E8 transition envelope.

This directory does not claim that `4_21` is the only possible high-compression geometry.

It is currently used because:

* it supports triangle-packing evaluations,
* appears in current survivor studies,
* and is practical for simulation work.

## LCO Work Interpretation

Within this interpretation, mass-like behavior corresponds to sustained LCO refinement work required to preserve survivor persistence under compression.

Lower-work regimes correspond to:

* longer persistence windows,
* lower mismatch burden,
* and greater projection stability.

Higher-work regimes correspond to:

* narrower stability windows,
* increased decay tendency,
* and greater sensitivity to compression pressure.

This interpretation remains RCMT-local.
