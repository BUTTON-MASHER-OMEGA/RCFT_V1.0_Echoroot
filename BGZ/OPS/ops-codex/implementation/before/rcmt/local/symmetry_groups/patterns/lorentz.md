## Purpose

This file defines the **Lorentz pattern** in RCMT.

The Lorentz pattern describes how boundary-compatible frames transform under an `SO(3,1)`-type generator/action structure.

This is a pattern, not an ontology claim.

---

## PATTERN TYPE

- pattern class: boundary/frame pattern
- symmetry source: `SO(3,1)`-type structure
- primary structure: boundary-compatible frame alignment
- identity status: alignment-dependent

---

## CONCEPTUAL DESCRIPTION

In this RCMT pattern, Lorentz-like behavior is modeled as a transformation pattern between boundary-compatible frames.

It does not define spacetime as a fundamental container.

It describes how relational frame descriptions remain mutually compatible under admissible transformation.

---

## STRUCTURAL ROLE

The Lorentz pattern acts on:

- boundary frames
- projection grammars
- admissible measurement orientations
- local relational descriptions

It does not act on absolute spacetime coordinates.

---

## GENERATOR ROLE

A Lorentz generator defines an infinitesimal boundary/frame adjustment.

The generator does not preserve identity.

It defines a permitted direction of frame transformation.

---

## ACTION ROLE

A Lorentz action is a finite frame transformation built from Lorentz generators.

After the action, LCO evaluation determines whether:

- boundary compatibility remains stable
- the structure relocks into a compatible frame basin
- alignment fails

---

## REPRESENTATION ROLE

A Lorentz representation describes how a relational structure responds to admissible boundary/frame transformations.

It records frame-response behavior, not guaranteed identity preservation.

---

## ADMISSIBILITY CONDITIONS

The Lorentz pattern is admissible when:

1. the transformation is allowed by the symmetry chain
2. boundary compatibility remains intact
3. projection grammar remains valid
4. mismatch remains below threshold
5. LCO evaluation accepts the transformed frame relation

---

## FAILURE MODES

The Lorentz pattern fails when:

- boundary compatibility breaks
- projection grammar becomes invalid
- mismatch exceeds threshold
- frame alignment cannot be maintained

---

## NON-ONTOLOGY CLAUSE

Lorentz structure is not treated as proof of fundamental spacetime ontology in this pattern.

It is treated as downstream relational boundary/frame transformation behavior.
