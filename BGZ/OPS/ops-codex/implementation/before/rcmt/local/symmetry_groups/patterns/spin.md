## Purpose

This file defines the **spin pattern** in RCMT.

The spin pattern describes how an internal mode grammar may transform under an `SU(2)`-type generator/action structure.

This is a pattern, not an ontology claim.

---

## PATTERN TYPE

- pattern class: mode pattern
- symmetry source: `SU(2)`-type structure
- primary structure: internal mode orientation
- identity status: alignment-dependent

---

## CONCEPTUAL DESCRIPTION

In this RCMT pattern, spin is modeled as a relational pattern of internal orientation.

Spin does not describe a small object rotating in space.

It describes how a mode responds to admissible internal transformations while maintaining coherence under LCO evaluation.

---

## STRUCTURAL ROLE

The spin pattern acts on:

- mode grammar
- internal orientation
- local coherence alignment
- projection behavior

It does not act on absolute spatial coordinates.

---

## GENERATOR ROLE

A spin generator defines an infinitesimal internal mode-orientation change.

The generator does not preserve identity.

It only defines a permitted direction of internal transformation.

---

## ACTION ROLE

A spin action is a finite transformation built from spin generators.

After the action, LCO evaluation determines whether:

- alignment remains within the same basin
- the mode relocks into a compatible basin
- alignment fails

---

## REPRESENTATION ROLE

A spin representation describes how a mode responds to admissible spin actions.

It records transformation behavior, not guaranteed identity preservation.

---

## ADMISSIBILITY CONDITIONS

The spin pattern is admissible when:

1. the transformation is allowed by the symmetry chain
2. mode compatibility remains intact
3. mismatch remains below threshold
4. coherence remains within acceptable bounds
5. LCO evaluation accepts the transformed mode

---

## FAILURE MODES

The spin pattern fails when:

- internal orientation exceeds compatibility limits
- mode grammar breaks
- mismatch exceeds threshold
- the transformed mode cannot maintain alignment

---

## NON-ONTOLOGY CLAUSE

Spin is not treated as an intrinsic particle property in this pattern.

It is treated as a downstream relational description of internal mode orientation under admissible transformation.
