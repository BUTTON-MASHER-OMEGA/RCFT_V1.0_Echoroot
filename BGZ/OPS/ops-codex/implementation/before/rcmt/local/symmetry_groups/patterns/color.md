## Purpose

This file defines the **color pattern** in RCMT.

The color pattern describes how multi-component relational structures cycle through compatibility states under an `SU(3)`-type generator/action structure.

This is a pattern, not an ontology claim.

---

## PATTERN TYPE

- pattern class: mode-compatibility pattern
- symmetry source: `SU(3)`-type structure
- primary structure: multi-mode compatibility
- identity status: alignment-dependent

---

## CONCEPTUAL DESCRIPTION

In this RCMT pattern, color is modeled as a relational compatibility pattern among coupled mode components.

Color does not describe a literal color or intrinsic object property.

It describes how a structured set of mode relations maintains admissible compatibility under transformation.

---

## STRUCTURAL ROLE

The color pattern acts on:

- coupled modes
- shard compatibility
- internal routing structure
- projection grammar

It does not act on absolute spatial coordinates.

---

## GENERATOR ROLE

A color generator defines an infinitesimal compatibility-routing change among coupled components.

The generator does not preserve identity.

It defines a permitted direction of internal relational reconfiguration.

---

## ACTION ROLE

A color action is a finite compatibility transformation built from color generators.

After the action, LCO evaluation determines whether:

- compatibility remains within the current basin
- the structure relocks into a compatible basin
- alignment fails

---

## REPRESENTATION ROLE

A color representation describes how a coupled relational structure responds to admissible compatibility transformations.

It records behavior under transformation, not guaranteed identity preservation.

---

## ADMISSIBILITY CONDITIONS

The color pattern is admissible when:

1. the transformation is allowed by the symmetry chain
2. coupled mode compatibility remains intact
3. mismatch remains below threshold
4. projection grammar remains valid
5. LCO evaluation accepts the transformed structure

---

## FAILURE MODES

The color pattern fails when:

- coupled mode compatibility breaks
- routing becomes non-admissible
- mismatch exceeds threshold
- the structure exits all compatible basins

---

## NON-ONTOLOGY CLAUSE

Color is not treated as an intrinsic particle property in this pattern.

It is treated as downstream relational compatibility behavior among coupled modes.
