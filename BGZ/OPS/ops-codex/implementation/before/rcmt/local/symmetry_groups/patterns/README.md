# RCMT Symmetry Patterns

## Document Contract

- owner: RCMT

- depends_on: parent symmetry-group contracts
- authority: non-canonical
- compression_rule: omit unless a downstream interpretation capsule is requested

## Purpose

This directory contains **reference transformation patterns** for RCMT.

Patterns demonstrate how symmetry-derived generators and actions may be applied to relational structures.

Patterns are:

- reusable
- illustrative
- provisional
- non-authoritative

They do not introduce new invariants, new groups, or new ontology.

---

## SCOPE

Patterns may describe common transformation structures such as:

- spin-like mode rotation
- charge-like phase alignment
- color-like compatibility cycling
- Lorentz-like boundary/frame adjustment

These are not upstream facts.

They are downstream modeling patterns that must compile against:

1. RCF core constraints
2. RCMT physics invariants
3. `symmetry_chain`
4. `generators.md`
5. `actions.md`
6. `representations.md`

---

## ROLE

Patterns provide:

- starter structures
- modeling examples
- reusable transformation templates
- intuition for how allowed groups act in RCMT

They are not required by RCMT.

---

## REPLACEMENT RULE

If a pattern fails RCF constraints or is outperformed by a cleaner construction, it is replaced without preserving authority.

---

## STATUS

All patterns in this directory are provisional unless explicitly promoted by later validation.
