# RCMT — Relational Coherence Mode Theory

RCMT is the physics‑focused theory built within the Relational Coherence Framework (RCF).
Where RCF provides the upstream relational substrate and structural rules, RCMT applies those
rules to physical systems, symmetry, dynamics, and projection.

RCMT is not a standalone framework.
It is a **downstream theory** compiled against the RCF upstream core.

Research Status

RCMT is an active downstream interpretation built on RCF. Documents describe the current architecture and hypotheses under evaluation. Mathematical derivations, simulations, and empirical mappings are ongoing. The repository is intended to evolve as coherence improves.

---

## What RCMT Is

- A mode‑based physical theory built on **relational coherence**.
- A dual‑lane architecture using:
  - **SO(3,1) × SO(4)** for geometric projection
  - **Sp(8)** for mode‑space, memory, and stochastic structure
- A model of physical behavior as **local mode selection** under boundary constraints.
- A finite, adjacency‑first alternative to field‑first or metric‑first formulations.
- A theory that explains:
  - mass as projected mode‑resistance
  - randomness as unresolved Sp(8) structure
  - decoherence as mode diffusion
  - measurement as boundary‑driven mode resolution
  - entanglement as shared‑boundary constraint negotiation
  - dark matter as non‑projectible modes
  - cosmic structure as coherence basins anchored by SMBHs

RCMT provides **mechanisms**, not metaphysics.

---

## What RCMT Is Not

- Not a modification of the RCF upstream core.
- Not a quantum field theory, string theory, or metric‑first gravity theory.
- Not a unification program in the traditional sense.
- Not a replacement for RCF — it depends on RCF’s invariants and structure.
- Not a domain‑general framework; it is physics‑specific.

RCMT does not redefine upstream invariants.
It compiles **downstream** from them.

## Build Expectations

RCMT assumes:

1. The RCF upstream core (`rcf_compressed.md`) is present and unchanged.
2. All RCMT invariants are defined in `invariants.md`.
3. All symmetry and projection rules are explicit and local.
4. No global curvature groups or non‑compact symmetries are introduced.
5. All mode‑selection behavior is expressed through the LCO.

Any RCMT module must compile cleanly against the RCF upstream structure.
